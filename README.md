# ☕ 도넛도넛 카페 랜딩페이지

간단한 카페 소개용 원페이지 랜딩페이지입니다. 순수 HTML/CSS로 제작되어 별도 빌드 과정 없이 바로 열어볼 수 있습니다.

> 마지막 업데이트: 2026-08-15 17:48:16 KST

## 미리보기

`index.html`을 브라우저로 열면 아래 섹션들을 확인할 수 있습니다.

- **Hero** – 카페 소개 문구와 메뉴 바로가기 버튼
- **About** – 카페 소개 및 특징 3가지
- **Menu** – 음료/베이커리 메뉴와 가격
- **Location** – 위치, 영업시간, 연락처
- **Footer** – 저작권 및 문의 이메일

## 기술 스택

- HTML5
- CSS3 (Flexbox, Grid, 반응형 디자인)

## 실행 방법

별도 설치 없이 `index.html` 파일을 더블클릭해서 브라우저로 열면 됩니다.

```bash
git clone https://github.com/wonyryu-blip/landing.git
cd landing
start index.html   # Windows
```

## 파일 구조

```
landing/
├── index.html   # 페이지 마크업
├── style.css    # 스타일시트
└── README.md
```
